# ADR-001: ユーザーログイン機能の設計方針

## 概要

ユーザーログイン機能のアーキテクチャ設計を決定する。

## 背景

要件：ユーザーログイン機能を作成したい。

- **Functional:** ユーザー名とパスワードでログインできる。エラーメッセージを表示する。
- **UX:** レスポンシブデザインで、モバイルでも使いやすい。
- **Business:** 優先度 High。来週金曜日まで納期。
- **Org:** 既存の認証システムと統合する。セキュリティ要件を満たす。
- **Social:** パスワードは暗号化して保存する。GDPR に準拠する。

## 検討

### Functional Perspective

**必須機能:**
- ユーザー名/パスワード認証
- ログイン/ログアウト
- セッション管理
- エラーハンドリング（無効なユーザー名、パスワード、アカウントロックなど）

**拡張機能（後期実装）:**
- 2FA（二要素認証）
- パスワードリセット
- 複数デバイス同期

### UX Perspective

**レスポンシブデザイン:**
- モバイルファーストアプローチ
- 最小幅：320px
- フレックスボックスレイアウト

**アクセシビリティ:**
- 適切なラベルと ARIA 属性
- キーボードナビゲーション
- フォーカス管理
- エラーメッセージの明確な表示

**ユーザー体験:**
- 直感的なフォームデザイン
- リアルタイムバリデーション
- 成功/失敗の明確なフィードバック
- ローディング状態の表示

### Business Perspective

**優先度:** High
**納期:** 来週金曜日

**セキュリティ要件:**
- HTTPS 必須
- パスワードハッシュ化（bcrypt/Argon2）
- セッショントークンの安全な管理
- CSRF 保護

**コンプライアンス:**
- GDPR 準拠（データ保護）
- パスワードポリシー（最小文字数、特殊文字など）

### Org Perspective

**技術スタック:**
- 既存認証システムとの統合
- セキュリティ要件を満たすライブラリ
- 型安全な実装（TypeScript）

**インフラ:**
- 環境変数による機密情報の管理
- 環境別設定（dev/staging/prod）

### Social Perspective

**プライバシー:**
- パスワードは暗号化して保存
- 最小限のデータ収集
- ユーザー同意の取得

**倫理的配慮:**
- 過度なデータ収集の回避
- ユーザーコントロールの提供
- 透明性のあるデータ使用

## 設計決定

### 技術スタック

```typescript
// 認証サービス
- bcrypt または Argon2 (パスワードハッシュ化)
- JWT (セッション管理)
- http-only cookies (CSRF 保護)

// フロントエンド
- React (または既存の UI フレームワーク)
- レスポンシブデザイン (CSS Flexbox/Grid)
- アクセシビリティ対応
```

### データモデル

```typescript
interface User {
  id: string;
  username: string;
  passwordHash: string;
  createdAt: Date;
  updatedAt: Date;
  // GDPR: 削除フラグ
  deletedAt?: Date;
}

interface LoginRequest {
  username: string;
  password: string;
}

interface LoginResponse {
  success: boolean;
  token?: string;
  error?: string;
}
```

### セキュリティ対策

1. **パスワード保存:**
   - bcrypt でハッシュ化 (cost: 12)
   - 平文パスワードは保存しない

2. **セッション管理:**
   - JWT トークン（http-only cookie）
   - トークン有効期限：24 時間
   - Refresh token によるリフレッシュ

3. **CSRF 保護:**
   - SameSite=Strict
   - CSRF トークン

4. **入力検証:**
   - サーバーサイドでの完全検証
   - XSS 対策（出力エスケープ）

### GDPR 対応

1. **データ最小化:**
   - 必要なデータのみ収集
   - 不要なデータは削除

2. **ユーザー権利:**
   - 本人確認（本人確認書類）
   - データ削除（忘れられたアカウント）
   - データエクスポート

3. **同意管理:**
   - 同意の記録
   - 同意撤回の仕組み
